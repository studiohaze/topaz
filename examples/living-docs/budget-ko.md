# 이번 달 가계부

**스스로 계산하는** 가계부입니다. 아래 기록을 고치면 — 거래를 추가하거나 한도를 바꾸면 —
요약 표가 즉시 다시 계산됩니다. 문서 전체가 하나의 오프라인 WASM 산출물이라, **저장**하면
재현성 해시가 찍히고 다시 열면 숫자가 그대로 재현됩니다. (이 문서를 여는 렌더러도, 아래
계산 블록도 — 전부 한글 식별자로 쓴 **토파즈**입니다.)

## 요약

```topaz
let 예산들 = [
  { 분류: "식비", 한도: 400 },
  { 분류: "월세", 한도: 1200 },
  { 분류: "교통", 한도: 120 },
]
let 거래들 = [
  { 분류: "식비", 금액: 52 },
  { 분류: "월세", 금액: 1200 },
  { 분류: "식비", 금액: 18 },
  { 분류: "교통", 금액: 44 },
  { 분류: "식비", 금액: 23 },
]
let mut 지출: Map<string, int> = Map.new()
for 거래 in 거래들 {
  지출.insert(거래.분류, (지출.get(거래.분류) ?? 0) + 거래.금액)
}
let mut 행들 = map(예산들, 항목 => {
  let 쓴돈 = 지출.get(항목.분류) ?? 0
  ({ 분류: 항목.분류, 예산: 항목.한도, 지출: 쓴돈, 잔액: 항목.한도 - 쓴돈 })
})
let 총예산 = reduce(행들, 0, (누적, 행) => 누적 + 행.예산)
let 총지출 = reduce(행들, 0, (누적, 행) => 누적 + 행.지출)
행들.push({ 분류: "합계", 예산: 총예산, 지출: 총지출, 잔액: 총예산 - 총지출 })
행들
```

`예산들`에 있는 분류마다 한 행이 나옵니다(지출은 `거래들`에서 분류별로 합산). 예산에 없는
분류의 거래는 표에 나타나지 않으니, 먼저 `예산들`에 추가하세요. **합계** 행은 위 행들을
더한 값이라 항상 칸과 일치합니다. **잔액**이 음수면 예산 초과입니다.

## 이번 주 일별 지출

(블록은 격리 실행되므로, 위 거래에서 자동으로 끌어오지 않고 명시한 주간 수열입니다.)

```topaz
[52, 70, 18, 44, 23, 0, 31]
```

> 반전: 이 문서를 HTML로 바꾸는 렌더러도, 위 가계부를 계산하는 블록도 — 모두 같은 언어
> **토파즈**로, 한글 변수·함수 이름으로 쓰여 브라우저에서 서버 없이 돕니다. 저장하면 해시가
> 찍혀, 다시 열었을 때 계산 결과가 그대로 재현됨을 확인합니다.
