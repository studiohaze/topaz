# Contributing

Thanks for taking the time to look at Topaz. Bug reports and suggestions are
welcome as [issues](https://github.com/studiohaze/topaz/issues).

This repository doesn't take pull requests. The compiler sources here are
generated from the release source, so a fix lands there first. It then reaches
this repository, the website and the official CLI together in the next release.

If you've found a fix, describe it in the issue. A small program that shows the
problem helps more than anything else. Please include the output of
`topaz version` or `topaz-core-kit --version` and your platform.

Reports that lead to a change are credited in the release notes.

Security problems go through private reporting instead. See
[SECURITY.md](SECURITY.md).
