Каждая программа на этой странице была выполнена тулчейном v0.3 ровно в таком виде, а напечатанный вывод зафиксирован байт в байт верификатором сайта. Что существует сегодня и чем это доказано — на странице [Состояние тулчейна](/ru/docs/status).

## Первая программа

Создайте файл `hello.tpz`:

```topaz
let greeting = "Hello, Topaz!"
print(greeting)
```

Запустите его:

```text
topaz run hello.tpz
```

```text output
Hello, Topaz!
```

Это весь цикл: один файл, `topaz run`, вывод. Никакого скелета проекта, манифеста или шага сборки.

## Тур в десять строк

`tour.tpz` затрагивает ядро языка — `match` с условиями и диапазонами, изменяемый `Map`, функцию высшего порядка и значение по умолчанию для опционала:

```topaz
function classify(n: int) -> string {
    return match n {
        case 0 => "zero"
        case x if x < 0 => "negative"
        case 1..99 => "small"
        case _ => "large"
    }
}

let mut report: Map<string, string> = Map.new()
for n in [-5, 0, 42, 1000] {
    report.insert("{n}", classify(n))
}

print("{report.keys}")
print("{map([1, 2, 3], (x: int) => x * x)}")
print("{toInt("42") ?? 0}")
```

```text
topaz run tour.tpz
```

```text output
[-5, 0, 42, 1000]
[1, 4, 9]
42
```

Три вещи, на которые стоит обратить внимание:

- `match` — это выражение: `classify` возвращает его результат напрямую. В ветвях допустимы литералы, диапазоны, привязки и условия `if`.
- Интерполяция `"{…}"` — единственный способ форматировать строки; она работает для любого значения, включая `report.keys`.
- `toInt("42")` возвращает опционал, а `??` подставляет значение по умолчанию. Ничто не преобразуется молча.

## Когда программа останавливается

Выход за границы массива в Топазе — не ошибка, которую можно перехватить, а **fault**: программа останавливается, и тулчейн печатает диагностику. `fault.tpz`:

```topaz
let xs = [10, 20, 30]
let i = 7
print("{xs[i]}")
```

```text
topaz run fault.tpz
```

```text output
error[TPZ4001]: index 7 is out of bounds for an array of length 3
 --> fault.tpz:3:9
  |
3 | print("{xs[i]}")
  |         ^^^^^

```

Процесс завершается с ненулевым кодом. Фолт означает нарушение контракта; отсутствие значения, с которым вы собираетесь работать, моделируется опционалами — см. [Обработку ошибок](/ru/docs/concepts/error-handling).

## Модули в двух файлах

Каталог файлов `.tpz` — это **юнит**. Файлы импортируют друг друга по имени; единственный механизм видимости — `export`. `util.tpz`:

```topaz
export function shout(s: string) -> string {
    return s + "!"
}

export let greeting: string = "hello"
```

`main.tpz` в том же каталоге:

```topaz
import util

print(util.shout(util.greeting))
```

```text
topaz run main.tpz
```

```text output
hello!
```

Резолвер находит `util.tpz` рядом с входным файлом — без манифеста и настройки путей. Полные правила (пути, коллизии, циклы, порядок инициализации) описаны в разделе [Модули](/ru/docs/concepts/modules).

## Проверка тулчейна

Если у вас есть сборка тулчейна, сначала проверьте, что это за сборка:

```text
topaz version
```

```text output
topaz 0.3.0 (Topaz v5.2, locked)
```

Публичного установщика пока нет — статус дистрибуции отслеживается на [странице состояния](/ru/docs/status).
